# Quartermaster

The Quartermaster is an resident vendor that will spawn once the following conditions have been met
There is an empty House.
All wayfarers in the game world have more than between them in their inventories.
He will also spawn as the starter resident instead of the Pathkeeper when the world seed is "not the bees!" or "not the bees".
Note that only coins in the main inventory or coin slots are counted; savings stored in a portable storage item like the Piggy Bank do not count toward the requirement. If the Quartermaster is killed, he will only respawn if the above conditions are met again. This means all wayfarers need to have over in their combined inventories.
