# Verdant Oracle

The Verdant Oracle is an resident vendor that will spawn once the following criteria have been met
There is an empty house.
Either the Watcher of the Rift, Abyssal Devourer, Sanguine Intellect, Ossuary Warden or Lepus has been defeated.
In addition to selling items, the Verdant Oracle can also report the percentages of Umbral Blight/Sanguine Reach and Luminous Expanse that exist in the current world.
