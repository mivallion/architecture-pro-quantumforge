# Задание 4. Локальный RAG-бот

## Результат

Реализован RAG-пайплайн над индексом из задания 3:

1. `Qwen/Qwen3-Embedding-0.6B` кодирует запрос через `encode_query` с
   L2-нормализацией и размерностью 512 — так же, как при построении индекса.
2. Долгоживущий `FaissRetriever` выполняет точный inner-product поиск и берёт
   тексты и метаданные чанков из SQLite.
3. Prompt builder добавляет два few-shot примера из Aetherfall и размечает
   найденные чанки как `[S1]`, `[S2]` и т. д.
4. Локальная `qwen3:4b-instruct-2507-q4_K_M` генерирует ответ через Ollama.
5. `RagService` принимает только ответы с валидными ссылками на переданные
   чанки и сам формирует список источников. При недостатке данных возвращается
   точная фраза: `Я не знаю: в базе знаний недостаточно информации.`
6. Telegram-адаптер передаёт текстовые сообщения сервису и отправляет ответ.

Основные файлы:

- `app/retrieval.py` — загрузка FAISS один раз и поиск;
- `app/prompts.py` — grounded prompt, few-shot и формат обоснования;
- `app/llm.py` — асинхронный Ollama-клиент;
- `app/rag.py` — оркестрация и проверка цитат;
- `app/telegram_bot.py` — Telegram handlers;
- `app/bot.py` — запускаемая точка входа;
- `app/query_rag.py` — локальный запрос без Telegram.

## Обоснование вместо скрытого Chain-of-Thought

Задание просит показывать шаги рассуждения. Бот выводит короткое проверяемое
`Обоснование` со ссылками `[S…]`, но не запрашивает и не раскрывает скрытую
цепочку рассуждений модели. Это сохраняет учебную цель: пользователь видит,
какие факты привели к ответу и из каких чанков они взяты.

## Настройки для MacBook Air M1, 8 ГБ

- LLM: квантованная Qwen3 4B, около 2,5 ГБ;
- `num_ctx=2048`, `num_predict=384`, `temperature=0.1`;
- одновременно обрабатывается один RAG-запрос;
- FAISS использует один OpenMP thread для совместимости PyTorch/FAISS на ARM;
- `OLLAMA_KEEP_ALIVE=0` по умолчанию выгружает LLM после ответа и освобождает
  память; при достаточной памяти его можно заменить, например, на `5m`;
- embedding-модель загружается из локального Hugging Face cache без сетевой
  проверки. Для первого скачивания при построении индекса это ограничение не
  используется.

## Установка и запуск

Из корня репозитория:

```bash
python3.11 -m venv venv
venv/bin/pip install -r app/requirements.txt
brew install ollama
OLLAMA_FLASH_ATTENTION=1 OLLAMA_KV_CACHE_TYPE=q8_0 ollama serve
ollama pull qwen3:4b-instruct-2507-q4_K_M
```

Локальный запрос без Telegram:

```bash
venv/bin/python -m app.query_rag "Кто лечит героя и снимает дебаффы?"
```

Telegram-бот:

```bash
# .env (файл должен быть в .gitignore и иметь права 600):
# TELEGRAM_BOT_TOKEN=<token from BotFather>
venv/bin/python -m app.check_telegram
venv/bin/python -m app.bot
```

Токен читается из `.env` или окружения и не сохраняется в коде. Значение из
окружения имеет приоритет над `.env`. Поддерживаются
`/start`, `/help`, текстовые вопросы и безопасные ответы на неизвестные команды
или нетекстовые сообщения.

## Конфигурация

| Переменная | Значение по умолчанию | Назначение |
|---|---|---|
| `OLLAMA_HOST` | `http://127.0.0.1:11434` | адрес Ollama API |
| `OLLAMA_MODEL` | `qwen3:4b-instruct-2507-q4_K_M` | генеративная модель |
| `OLLAMA_KEEP_ALIVE` | `0` | время удержания модели в памяти |
| `RAG_TOP_K` | `4` | число передаваемых в prompt чанков |
| `RAG_SCORE_THRESHOLD` | пусто | необязательный retrieval gate |
| `RAG_MAX_QUESTION_CHARS` | `2000` | максимальная длина вопроса |
| `RAG_MAX_CONTEXT_CHARS` | `6000` | бюджет контекста из чанков |
| `EMBEDDING_LOCAL_FILES_ONLY` | `true` | запрет сетевой проверки cache |

## Проверка retrieval

Набор `Task4/eval_cases.json` содержит 5 известных и 5 отсутствующих в базе
вопросов. Запуск:

```bash
venv/bin/python -m app.evaluate_retrieval
```

Измеренный результат для `top_k=4`:

- нужный документ найден в top-4 для 5 из 5 известных вопросов;
- минимальный top-1 score известного вопроса: `0.4516`;
- максимальный top-1 score неизвестного вопроса: `0.6044`.

Диапазоны пересекаются, поэтому единый score threshold ошибочно отсеял бы
часть известных вопросов либо пропустил бы часть неизвестных. Порог по
умолчанию выключен; отказ обеспечивают grounded-инструкция и проверка цитат.
